## 4. 共通規則への整理（C）

少数の共通規則へ整理する方向は採用する。ただし、型等式だけによる独立性と、列挙モードだけによる束縛型の決定は採らない。

| 軸 | 最終的な整理 |
| --- | --- |
| 取得 | PlaceはCopy、移動は明示@move。一時値・取得済み所有値の分配は転送 |
| 選択 | receiver・列挙入口・構造Pattern・Scalar readでは限定した参照経路省略。明示スロット借用と単独名の束縛は読み替えない |
| 適合 | 期待型が確定した値位置では一つの共通表を使う |
| 権限 | 所有経路はルートのlet／var、借用経路は参照の権限。共有経路から排他権限を回復しない |
| 独立性 | 型等式と共通Loan・効果検査。領域分割の構築側が非重複・依存保持を保証する |

列挙モードは入口とreceiverの取得方法を決め、**反復で受け取る値の型は選択したIteratorのItem{step}が決める**。例えばSharedのResolvedRangeでもItemはisize、ByValueのSliceでもItemは共有参照である。Patternの場所からの束縛規則と、Iteratorからの値配送を一つの型対応表へ混同しない。
