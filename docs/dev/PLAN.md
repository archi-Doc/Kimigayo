## 1. Scope

Implement the finalized language of SPEC.md (Chapters 1–19 and 22) and the implementation contracts of [IMPL.md](../IMPL.md) (Chapters 20–21, the test execution profile and Appendix A) for the Windows x64 profile, excluding what Appendix D defers; ObjectCallCompatible stage 2 (Appendix D.2) is in scope. Work follows unfinished implementation items and their dependencies. Milestone Programs require explicit user instruction as implementation targets; existing program results remain evidence, not stopping conditions.

- **Generics:** the initial profile monomorphizes (§21.3.1). Generic code sharing is deferred.
- **Origins and the Contract/type system** (§8, §15) remain complete requirements; implementation limits never narrow them.
- **Async tasks and workers:** implementation is deferred by user instruction; the preserved plan is Appendix D. Remaining callable effect-bound integration is G78.
- **Adopted library contracts:** channel delivery is FIFO by successful-send commit order, and remaining items are completely destroyed one at a time in reverse order (SPEC §22.3.4). Apply these when the deferred async implementation resumes. Slice `firstIndexWhere(predicate:)` remains unimplemented within the existing library support boundary.
- **Proposal text changes** and **NativeAOT tests** need explicit instruction. Instructed intake or closure includes register updates and moves under AGENTS.
