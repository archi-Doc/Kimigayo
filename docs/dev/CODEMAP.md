# Compiler Code Map

Navigation to owners, entry points and representative tests; not a specification or support matrix. Required behavior is in [SPEC.md](../SPEC.md) and [IMPL.md](../IMPL.md), verified coverage in [STATUS.md](../STATUS.md), phases, canonical components, structure limits and the stage ledger in [COMPILER_ARCHITECTURE.md](COMPILER_ARCHITECTURE.md), decisions in [DECISIONS.md](DECISIONS.md), diagnostic rules in [DIAGNOSTICS.md](DIAGNOSTICS.md). Entries are starting points: follow callers and shared data before editing, and select tests from their source ([VERIFICATION.md](VERIFICATION.md)).

Main path: source → Koto syntax → Binding (HIR columns) → MIR (build, validate, analyses; the MIR decides acceptance, DECISIONS R5-M185) → instance collection → MIR code generation (LLVM IR) → native tools.
