# Kimigayo Implementation Status

Current supported subsets, known defects and remaining limits. [SPEC](SPEC.md) and [IMPL](IMPL.md) define required behavior; a limit here never narrows them. [PLAN](dev/PLAN.md) owns next actions and issue IDs, [CODEMAP](dev/CODEMAP.md) implementation navigation, and the [program catalog](../tests/milestones/README.md) individual milestone states. Update only changed boundaries under [AGENTS Documentation](../AGENTS.md#documentation).

**Conformance qualification:** the 2026-10-15 specification revision and follow-up changed language and implementation contracts. The recorded support below does not establish conformance to every revised rule; that audit remains PLAN S1015. The compiler still emits single-unit `kimi.check/2`, not the specified `kimi.check/3` command envelope. The 2026-10-17 and 2026-10-19 revisions of SPEC §15.6 (A5's simplifications and Loan identity by base; the Loan ending by exact Move-Path prefix and loss P12; storage the body does not own following its holder; in §15.6.4, the widening of parameter-dependent effects on a projection with a recursive base, [INTEGRATED](../draft/INTEGRATED.md)) belong to the MIR pipeline's A4 and A5, which are not complete (A4 widens since DECISIONS R4-M87; a recursive base G170 hides keeps its atom, and G170's false Copy at a two-step `CopyTree` projection rejects some valid callers in uninstantiable code on the MIR); until R6-check the default pipeline keeps the earlier rules ([A5 plan](../draft/Proposals/2026-10-16%20Complete%20Polonius%20A5%20Plan.md) §9.2, OD5). It accepts some programs the revised SPEC rejects, such as a write of a part of a local, or a complete write through a reference, followed by a conflict with a Loan the old value carried, and rejects some it accepts, such as `replace` of a reference while a child Reborrowed through it is live, or a write through an outer reference replaced while a child formed through its old value is live, or a default that Copies an existing shared borrow past a shared dereference (`y: ref/i32 during a = x@follow@ref` with `x: ref/i32 during a`). Tests of the earlier rules carry the trait `OldRule`; a corpus row states them in an `Old` entry (DECISIONS R4-M60).

Detailed historical descriptions and evidence references remain in [the pre-cleanup snapshot](https://github.com/archi-Doc/Kimigayo/blob/5287ae5058fbc355a8b39ee4685d83b5ebb857ad/docs/STATUS.md) and Git history. New unit evidence belongs in commits and `artifacts/verify/`, not in this document.
